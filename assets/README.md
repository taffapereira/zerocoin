# Assets Folder

This folder contains image assets for the Zero Coin landing page.

## Required Images

Please add the following images to this folder:

1. **logo-full.png** - Full horizontal logo for the header
   - Recommended size: 200x50px (or similar aspect ratio)
   - Transparent background preferred

2. **logo-icon.png** - Icon version of the logo (just the "Z" symbol)
   - Recommended size: 256x256px
   - Transparent background
   - Used for favicon and MetaMask token icon

3. **hero-banner.png** (Optional) - Background image for hero section
   - Recommended size: 1920x1080px
   - Can be abstract or crypto-themed

4. **bg-abstract.png** (Optional) - Abstract background pattern
   - Can be used throughout the site for visual interest

## Notes

- The landing page uses CSS gradients as fallback when images are not available
- All images should be optimized for web (compressed)
- PNG format with transparency is recommended for logos
- JPG format is acceptable for background images
